Toolzen

All-in-one online tools website built with Next.js 16, React 19 and Tailwind CSS 4. Toolzen is free and open source under the MIT licence. This guide takes you from download to a live, earning website.

Quick start: upload the toolzen folder, run npm install and npm run build, start the app, then open your domain in a browser. The web installer does the rest — no files to edit.

Introduction

Toolzen is a ready-to-run website with 156 online tools for images, PDFs, text, developers, converters, SEO and everyday calculations. 144 tools run inside the visitor's browser, so files are never uploaded: your server stays fast and cheap, and visitors' files stay private. 12 website checkers (DNS, WHOIS, SSL, HTTP headers, redirects…) run on your server with built-in protection against abuse.

The whole site can be translated into any language, including right-to-left languages such as Arabic and Urdu, and a built-in blog helps you bring in search traffic.

You earn money in two ways: advertising (Google AdSense or any ad network) and paid plans that raise file-size limits, unlock Pro tools and remove ads. Payments are accepted through Stripe, PayPal, Razorpay or manual bank transfer.

Requirements

ItemRequirement
Node.js20.9 or newer (22 LTS recommended). Node.js 22.13+ is needed only for the SQLite database option.
DatabaseMySQL 5.7+ / MariaDB 10.3+ (recommended for production), or the built-in SQLite option (no database server needed).
HostingAny host that runs Node.js apps: a VPS, cPanel with “Setup Node.js App”, Plesk, Docker, Railway, Render, etc.
MemoryAt least 1 GB RAM to build (npm run build). Running the site needs about 200–300 MB.
Writable folderThe storage folder must be writable (configuration, SQLite database and uploaded logos are stored there).
Static-only hosting (plain HTML hosting, GitHub Pages) cannot run Toolzen because the admin panel, accounts and payments need a Node.js server.

Installation

Pick the guide that matches your hosting. Every method ends with the web installer.

cPanel / shared hosting (Setup Node.js App)

  1. In cPanel open MySQL® Databases. Create a database and a user, then add the user to the database with All privileges. Write down the database name, username and password.
  2. Open File Manager and upload toolzen.zip (the toolzen folder from the package, zipped) to your home folder, e.g. /home/youruser/toolzen, and extract it. Do not put it inside public_html.
  3. Open Setup Node.js App → Create Application:
    • Node.js version: the newest available (22.x recommended)
    • Application mode: Production
    • Application root: toolzen
    • Application URL: your domain or subdomain
    • Application startup file: server.js
    Click Create.
  4. Click Run NPM Install and wait until it finishes.
  5. Copy the command shown at the top of the page (it looks like source /home/youruser/nodevenv/toolzen/22/bin/activate && cd /home/youruser/toolzen). Open Terminal in cPanel, paste it, then run: 
    npm run build
    The build takes 1–4 minutes.
  6. Back in Setup Node.js App, click Restart. Open your domain: you will see the installer.
If the build stops with “JavaScript heap out of memory” your plan limits memory. Build on your own computer instead (npm install && npm run build), then upload the whole folder including the .next folder, and only run “Run NPM Install” + “Restart” on the server.

VPS (Ubuntu) with PM2 and Nginx

  1. Install Node.js 22 and PM2: 
    curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs nginx
sudo npm install -g pm2
  2. Install MySQL (or use SQLite and skip this step): 
    sudo apt install -y mysql-server
sudo mysql -e "CREATE DATABASE toolzen CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'toolzen'@'localhost' IDENTIFIED BY 'choose-a-strong-password';
GRANT ALL PRIVILEGES ON toolzen.* TO 'toolzen'@'localhost'; FLUSH PRIVILEGES;"
  3. Upload the toolzen folder to /var/www/toolzen, then: 
    cd /var/www/toolzen
npm ci
npm run build
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup
  4. Create /etc/nginx/sites-available/toolzen: 
    server {
    listen 80;
    server_name tools.example.com;
    client_max_body_size 10m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
    Enable it and add a free SSL certificate: 
    sudo ln -s /etc/nginx/sites-available/toolzen /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d tools.example.com
  5. Open https://tools.example.com to run the installer.

Docker

The package includes a Dockerfile and a docker-compose.yml with MySQL:

cd toolzen
docker compose up -d --build

Open http://your-server:3000. In the installer choose MySQL with host db, database toolzen, user toolzen, password toolzen (change these in docker-compose.yml first). The storage folder is kept in a Docker volume.

Vercel (with a cloud MySQL database)

Vercel has no permanent disk, so the web installer and SQLite can't be used there. Instead, Toolzen is configured with environment variables and a cloud MySQL-compatible database such as TiDB Cloud Serverless (free tier), Aiven or PlanetScale.

  1. Create a database. In TiDB Cloud: create a Serverless cluster in the region closest to your visitors, open Connect, generate a password and note the host, port (4000), user and password. In the SQL editor run CREATE DATABASE toolzen;
  2. Push the toolzen folder to a GitHub repository (keep it private).
  3. In Vercel click Add New → Project, import the repository and set Root Directory to the folder that contains package.json.
  4. Add these Environment Variables: 
    DB_DRIVER=mysql
DB_HOST=your-cluster-host
DB_PORT=4000
DB_USER=xxxxxxxx.root
DB_PASSWORD=your-password
DB_NAME=toolzen
DB_SSL=true
APP_INSTALLED=true
ADMIN_EMAIL=you@example.com
ADMIN_PASSWORD=a-strong-password
ADMIN_NAME=Your Name
  5. Click Deploy. Tables are created automatically on the first visit and the administrator account is created from ADMIN_EMAIL / ADMIN_PASSWORD.
  6. In Vercel open Settings → Functions and choose the region closest to your database for the best speed.
On Vercel, uploaded logos and favicons are not kept (no permanent disk). Paste an image URL instead, e.g. from your own CDN, in Settings → General, or host on a VPS/cPanel where uploads are stored in the storage folder.

Local computer (for testing or customising)

cd toolzen
npm install
npm run dev

Open http://localhost:3000 and choose SQLite in the installer.

Web installer

  1. Requirements – checks the Node.js version and that storage is writable.
  2. Database – choose MySQL/MariaDB (enter host, port, database, user and password) or SQLite. Click Test connection, then Continue.
  3. Site & admin – enter your site name, the full site URL (e.g. https://tools.example.com) and the administrator account. Click Install now.

The installer creates all tables, default plans and pages, writes storage/config.json and locks itself (storage/installed.lock). Sign in at /login and open the admin panel at /admin.

To run the installer again (e.g. to switch databases), delete storage/installed.lock and storage/config.json and restart the app. Existing data in the old database is not deleted.

Admin panel

Open /admin while signed in as an administrator. The Dashboard shows users, active paid plans, this month's revenue, tool usage for the last 14 days, the most used tools, and a Finish setting up checklist.

Tools

  • Live – switch a tool off to hide it everywhere (menus, search, sitemap). Its URL returns 404.
  • Pro only – only users whose plan includes “Pro tools” can use it; others see an upgrade prompt.
  • Featured – shown in “Popular tools” on the home page.
  • Edit – change the display name, meta description (for search results) and the order within its category.

Plans & limits

One plan is marked as the free plan: its limits apply to visitors and free accounts. Paid plans can raise the maximum file size and files at once, unlock Pro tools and remove ads. Set a monthly price, a yearly price, or both (0 hides that billing period). Features (one per line) appear with a tick on the pricing page.

File limits are enforced in the visitor's browser, because files are never uploaded. They are a fair-use limit for your plans, not a security boundary.

Users & payments

  • Users – search, filter (paid, admins, banned), edit name/email/role, ban, reset passwords and give any user a paid plan until a date you choose.
  • Payments – every payment from every gateway. Bank transfers wait here with the customer's reference: click Approve to activate the plan, or Reject.

Pages & messages

Create content pages (About, Privacy policy, Terms…) in Markdown. They are published at /p/your-slug and can be linked in the footer. {site_name} and {site_email} are replaced automatically. Messages lists contact-form submissions; reply by email with one click.

Blog

Write articles in Markdown at Admin → Blog. Each post has a title, URL slug (/blog/your-slug), excerpt, cover image (upload or URL), meta description and status. Leave the publish date empty to publish now, or pick a future date (UTC) to schedule the post. Published posts appear at /blog, in the sitemap and, the latest three, on the home page. The Blog link appears in the header and footer once at least one post is published. Switch the whole blog off in Settings → General.

Tip: articles such as “How to compress a PDF for email” that link to your own tools are one of the most effective ways to get search traffic.

Languages & translation

  1. Open Admin → Languages and add a language. Pick one from the list (the code, names and text direction are filled in) or enter your own, e.g. pt-BR.
  2. Click Translate. Texts are grouped into Interface (menus, buttons, messages), Site texts (tagline, headline, footer, SEO texts), Categories and Tools (names, descriptions, steps and FAQs). Search, show untranslated texts only, and save page by page.
  3. Switch the language to Active. When two or more languages are active, visitors get a language switcher in the header. Their choice is remembered in a cookie.
  4. Choose the default language for visitors who haven't picked one.

Anything you leave empty falls back to English, so you can translate step by step. To translate offline (or with a translation service), click Download template: you get a JSON file with every text. Translate the values, keep the keys, and upload the file with Import. Export downloads the translations you have so far, to back them up or copy them to another site.

Included language packs: the folder toolzen/languages/ contains starter translations for Arabic (right to left) and Hindi: the whole interface, categories, and every tool's name and description. Add the language in Admin → Languages, then import ar.json or hi.json. They were prepared with translation software, so have a native speaker review them before you launch.

Right-to-left languages (Arabic, Hebrew, Persian, Urdu) flip the whole public site automatically. The admin panel stays in English. You can also change the English wording itself: open English in Admin → Languages and enter your own text.

Some labels inside individual tools (option names, for example) stay in English. The tool name, description, how-to steps, FAQ, shared buttons, file drop areas and all site pages are translatable.

Payment gateways

Choose your currency in Settings → Payments first; it must be supported by every gateway you enable. Prices are entered per plan.

Stripe (cards, Apple Pay, Google Pay – automatic renewal)

  1. In the Stripe Dashboard open Developers → API keys and copy the Secret key (sk_live_…, or sk_test_… for testing).
  2. Open Developers → Webhooks → Add endpoint:
    • URL: https://your-domain.com/api/payments/stripe/webhook
    • Events: invoice.paid, checkout.session.completed, customer.subscription.deleted
    Copy the Signing secret (whsec_…).
  3. In Toolzen open Settings → Payments, switch on Stripe, paste both keys and save.

Stripe products and prices are created automatically from your plans; you don't have to create them in Stripe. Customers can cancel automatic renewal from their account page and keep access until the end of the paid period.

PayPal

  1. Go to developer.paypal.com → Apps & Credentials, create an app and copy the Client ID and Secret (Sandbox for testing, Live for real payments).
  2. In Settings → Payments switch on PayPal, select the matching mode and paste both values.

PayPal payments are one-off: a monthly or yearly purchase adds that period to the user's plan.

Razorpay (India: UPI, cards, netbanking)

  1. In the Razorpay Dashboard open Account & Settings → API Keys and generate a key.
  2. Paste the Key ID and Key secret in Settings → Payments and switch Razorpay on. Set the currency to INR.

Customers pay on a Razorpay payment page; the signature of the return request is verified before the plan is activated.

Bank transfer

Switch on Bank transfer and write your bank details in Payment instructions. Customers submit their transaction reference; you approve it in Admin → Payments.

Google AdSense

  1. Apply for AdSense with your domain. AdSense requires useful content pages — Toolzen already includes About, Privacy policy and Terms pages plus how-to text and FAQs on every tool.
  2. Paste the AdSense code (<script async src="https://pagead2.googlesyndication.com/…">) in Settings → Ads → Ad network script. This enables Auto ads.
  3. Optionally create ad units in AdSense and paste their code into the slots: below the header, above/below each tool, tool sidebar and above the footer.
  4. Paste the line AdSense gives you into ads.txt (served at /ads.txt).
  5. Switch on Show ads and save.

Ads are hidden for users whose plan is marked “No advertisements”.

Email (SMTP)

Email is used for password reset links and contact-form notifications. Enter your SMTP details in Settings → Email (any provider works: your hosting mailbox, Gmail with an app password, Brevo, Mailgun, Amazon SES…). Use port 587 with SSL off, or port 465 with SSL on. Send a test from Admin → System.

SEO

  • Every tool has its own page with a title, description, how-to steps and FAQ, plus structured data (WebApplication, FAQPage, BreadcrumbList).
  • /sitemap.xml and /robots.txt are generated automatically. Submit the sitemap in Google Search Console.
  • Set the Site URL in Settings → General so canonical URLs and the sitemap use your domain.
  • Change any tool's title or description in Admin → Tools → Edit.
  • Blog posts get article structured data (BlogPosting), Open Graph tags and sitemap entries.
  • The server SEO tools (DNS, SSL, headers, meta tags…) give visitors reasons to come back. They are rate-limited to 30 checks per minute per visitor and can't be used to reach private networks.

Adding a tool

  1. Add an entry to src/tools/registry.ts or a file in src/tools/defs/ (slug, name, category, icon, description, steps, FAQ). The icon is any Lucide icon name, e.g. "file-text".
  2. Create src/tools/components/your-slug.tsx — a client component. Copy word-counter.tsx or image-compressor.tsx as a starting point.
  3. Run npm run tools:generate (it registers the component and icon, and checks for mistakes), then npm run build.

More details are in src/tools/README.md. After editing code always run npm run build and restart the app.

Demo mode

Set the environment variable DEMO_MODE=true to make the admin panel read-only (everything can be viewed, nothing can be saved). Useful for a public demo. With ADMIN_EMAIL and ADMIN_PASSWORD set, the login page pre-fills that account for visitors, and its password and profile can't be changed. Add DEMO_SEED=true to fill the database with sample data.

Updating to a new version

  1. Back up the storage folder and your database.
  2. Replace all files except storage with the new version.
  3. Run npm install and npm run build, then restart the app.

Database changes are applied automatically the first time the new version starts. Your settings, users and payments are kept.

Troubleshooting

ProblemSolution
Blank page or “502 Bad Gateway”The app isn't running. Check that npm run build finished, then restart (cPanel: Restart; VPS: pm2 restart toolzen; logs: pm2 logs toolzen).
“storage folder is writable” failsGive the app user write access: chmod -R 775 storage (and chown it to the user running Node.js).
Database connection failsCheck host (usually localhost or 127.0.0.1), port 3306, and that the user has all privileges on the database. On cPanel the database and username include your account prefix, e.g. myacc_toolzen.
SQLite option failsSQLite needs Node.js 22.13+. Choose a newer Node.js version in your hosting panel or use MySQL.
Can't sign in after installing on HTTPS behind a proxyMake sure the proxy sends X-Forwarded-Proto and Host headers (see the Nginx example).
Server SEO tools say a site “could not be reached”Your server needs outgoing internet access (ports 53, 80 and 443). Some shared hosts block outgoing connections; ask your host to allow them.
A translation doesn't show upWith several app processes, translations are cached for up to a minute. Check that the language is Active and that the visitor picked it (or that it is the default).
Logo changes don't appearHard-refresh the browser (Ctrl + F5). Uploaded files are served from /uploads/….
Payments are not activatedFor Stripe, check the webhook URL and signing secret, and look at the webhook delivery log in Stripe. Set the correct Site URL.
Password reset emails don't arriveConfigure SMTP and use Admin → System → Send test. Check the spam folder.
I forgot the admin passwordUse “Forgot password” (needs SMTP). Otherwise ask another administrator to set a new password in Admin → Users, or delete storage/installed.lock, restart, and run the installer again with the same database and the same admin email: the installer sets the new password on the existing account and keeps all data.
