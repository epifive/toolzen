# Toolzen

All-in-one online tools website built with **Next.js 16**, **React 19** and **Tailwind CSS 4**.
156 tools for images, PDFs, text, developers, converters, SEO and everyday calculations — almost all
running in the visitor's browser, plus 12 server-side website checkers (DNS, WHOIS, SSL, headers…) —
with user accounts, paid plans, ads, a blog, multi-language/RTL support and a full admin panel.

The complete, illustrated guide is in [`../documentation/index.html`](../documentation/index.html) (open it in a browser).

## Quick start (local)

```bash
npm install
npm run dev
```

Open http://localhost:3000 — you will be redirected to the web installer at `/install`.
Choose **SQLite** for a zero-setup local database, or **MySQL** for production.

## Production

```bash
npm install
npm run build
npm start            # or: node server.js  (cPanel / Passenger / PM2)
```

Requirements: Node.js 20.9+ (22.13+ for the SQLite option) and a MySQL 5.7+/MariaDB 10.3+ database
or the built-in SQLite option. See the documentation for cPanel, VPS (PM2 + Nginx) and Docker guides.

## Project structure

```
src/
  app/(site)/          Public website (home, tools, blog, pricing, account, auth, pages)
  app/admin/           Admin panel
  app/install/         Web installer
  app/api/             Payment callbacks, webhooks, usage tracking and server tools (/api/tools/[slug])
  components/          Shared UI (ui/), site chrome (site/), tool building blocks (tool-ui/)
  lib/                 Server code: database, settings, auth, payments, mail
  lib/i18n/            Interface strings (messages.ts) and translation loading
  lib/server-tools/    Server-side SEO tools with SSRF protection
  lib/db/migrations.ts Database schema migrations (run automatically)
  tools/registry.ts    Core tool definitions; more in tools/defs/*.ts
  tools/components/    One client component per tool
  tools/loader.tsx     Generated by `npm run tools:generate`
storage/               Created at runtime: config.json, SQLite database, uploads
```

## Scripts

| Command             | Description                              |
| ------------------- | ---------------------------------------- |
| `npm run dev`       | Development server with hot reload       |
| `npm run build`     | Production build                         |
| `npm start`         | Start the production server              |
| `npm run start:server` | Start via `server.js` (hosting panels) |
| `npm run lint`      | ESLint                                   |
| `npm run typecheck` | TypeScript check                         |
| `npm run tools:generate` | Regenerate `tools/loader.tsx` and `tools/icons.tsx` after adding a tool |
